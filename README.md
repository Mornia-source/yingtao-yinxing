# 樱桃音形

自制 Rime 中州韵方案：自然码双拼 + 98五笔首末字根形码。

## 编码规则

- **单字**：自然码双拼全码（2位，不含辅助码） + 98五笔该字首位字根 + 末位字根（2位，不含末笔识别码）。例：廷=tytp，啊=aakk，我=woty，全=qrwg。双拼2位一打完，同音字就已经按字频排好队出现在候选里了（比如打"ui"就能看到 是/时/事/使/式……），不用非等形码也打完才能选字；形码留给需要精确定位某个字的时候用。
- **二字词**：全码 = 前字前两位 + 后字前两位；简码 = 前字前两位 + 后字首位（3位）。例：简单=jmdj/jmd，时间=uijm/uij。词组一律从3位编码起，2位编码专属于单字双拼（见上一条），这样双拼2位刚打完时，候选里只会出现同音单字，不会被词组抢占。
- **三字词**：全码 = 前两字首码 + 第三字前两位；简码 = 三字首码。例：不知道=bvdk/bvd，非常好=fihk/fih。
- **四字词**：四字首码。例：妙不可言=mbky。
- **五字及以上**：前三字首码 + 末字首码。例：踏破铁鞋无觅处=tpti。
- **ü 韵母注意**：j/q/x/y 后面的"u"实际是"ü"（续xù、语yǔ、去qù、句jù……），双拼要打 **v** 不是 u。例：继续=jixv（不是jixu），粤语=ytyv（不是ytyu）。有简码的词全码依然保留、不会被简码顶掉；如果打出来的字/词和预期不符，先检查一下是不是该用v的地方打成了u。

## 安装方法

1. 安装 [小狼毫 Weasel](https://github.com/rime/weasel/releases)（Windows）或其他中州韵前端。
2. 把本目录下的三个文件复制到 Rime 用户目录（Windows 一般是 `%APPDATA%\Rime`）：
   - `yingtao.schema.yaml`
   - `yingtao.dict.yaml`
   - `yingtao_chars.dict.yaml`
   - `yingtao_words.dict.yaml`
3. 编辑用户目录下的 `default.custom.yaml`（没有就新建），加入：

   ```yaml
   patch:
     schema_list:
       - schema: yingtao
   ```

4. 右键托盘图标"重新部署"。

## 数据来源与生成方法

- **98五笔字根参考（去末笔识别码）**：用户自行整理的"通用规范汉字8105字"参考表，每个字对应的98五笔码已手动去掉末笔识别码、只保留真实字根序列，是单字形码的首选数据源（`sources/wubi98_noident_8105.txt`）。
- 拼音数据、字频、词库：[iDvel/rime-ice](https://github.com/iDvel/rime-ice)（8105 常用字表 + 基础词库 + 成语词库）。
- 官方98五笔全码：[lotem/rime-wubi98](https://github.com/lotem/rime-wubi98)、汉字结构拆分：[hanzi-chai/pychai](https://github.com/hanzi-chai/pychai) —— 仅作为上面参考表覆盖不到的极少数生僻字（约32个）的备用近似算法。
- `../build/` 目录下的 Python 脚本（`shape.py` 形码计算、`zrm.py` 自然码双拼算法、`gen_chars.py`/`gen_words.py` 生成码表）可重新运行以更新/扩展码表；`../sources/` 存放了脚本依赖的原始数据快照。

## 已知局限

单字形码现在以用户提供的"98五笔去识别码"参考表为准（覆盖 8105 字表中的 8494 字，直接取参考表里字根序列的首字母+末字母，结果是精确的，不再依赖猜测）。只有约32个不在这份参考表里的生僻/异体字（如 車、卻、咲、牠等，本来就不属于通用规范汉字表），才会退回到"拆字库交叉验证 + 官方全码首尾近似"的旧算法，可能存在少量偏差；还有3个极生僻扩展汉字查不到五笔码，未收录进单字表。

如果后续发现某个字的形码不对，最快的办法是直接在 `yingtao_chars.dict.yaml` 里手动改那一行的码；如果是参考表本身就没有的生僻字，也可以在 `build/shape.py` 的 `CHAR_SHAPE_OVERRIDE` 里加一条手动修正。

## 编码位数越少优先级越高

不管当前打了几个字符、候选是单字还是词/句，永远按"候选自身编码位数"分档排序：2位（单字双拼）> 3位（词组简码）> 4位（全码），位数少的档在任何情况下都排在位数多的档前面，同一档内再按词频排序。三档的权重加成差（1亿 / 5千万 / 不加成）远大于任何真实词频，保证跨档时不会被词频反超。这也是为什么打"d"的时候"的"（2位）永远排第一，"第二""掉落"这类3位简码词会排在它后面、但仍然领先于4位全码词。

具体实现见 `build/tier_boost.py`，`gen_chars.py`/`gen_words.py` 生成码表时统一调用。

## 智能分词 / 长句连续输入 / 四码顶字

- `translator/enable_sentence: true`：允许词与词之间不用分隔符直接连打，输入法会自动按码表做分词组合成整句。
- `speller/auto_select: true` + `auto_select_pattern: "^[a-z]{4}$"`：只有凑满4位编码时才会自动把当前排名第一的候选上屏（经典五笔"四码顶字"手感）；2位、3位的简码不会被提前打断，可以继续挑候选或续打。
- 三个开关（中西文、半全角、繁简）都加了 `reset: 0`，避免继承别的方案里的全角/繁体状态，导致回车提交出来的字母变成全角。

另外，词库来源 rime-ice 是通用词库，个别口语化短语（如"手头紧"）可能没收录，可以自己在 `yingtao_words.dict.yaml` 里按同样规则追加。
